## Gotchas
- Local preview (python http.server) can serve a stale `wireframe.css`; cache-bust the stylesheet link before judging a screenshot.
- Fader is hidden (`is-away`, no pointer events) while the Home hero fills the view (deliberate). Fader tests must scroll past the hero before dragging. On phones it fades after 1.5s idle (`is-idle`).
- Navbar hover layout shift: pre-allocate transparent borders and keep constant `font-weight: 600` across default/hover/active.
- Never use `mask-composite` or multi-layer masks (headless Chromium 131 ignored the union and knocked out the hero wordmark). Texture tiles are alpha-only and tinted by palette tokens; no blend modes.
- Demo picker on Android: `booking-form.js` sets `accept` to `application/octet-stream` so Chrome shows Files only (any audio/video type in `accept` adds Camera/Camcorder/Recorder, and on-the-spot recordings failed to upload). Do not add media types back for Android. `contact.html?debug` shows the technical upload error on the page.
- Phone (2026-11-12, user decision, overrides the spec's "10+ digits"): US numbers only. 10 digits, area code 2-9, optional country code 1, a "+" must be "+1"; same rule in `booking-form.js` (`isUsPhone`) and the backend (`isUsPhone_`). The field auto-formats while typing to `(555) 123-4567` / `+1 (555) 123-4567` (`formatPhone`); numbers that cannot be US are left as typed. The live Apps Script still has the old rule until the backend is redeployed (Manage deployments -> Edit -> New version).
- Admin mode: this folder is not a git repo; reconcile with the real repo before the first live Save. Real GitHub Save is untested (CORS, token scope); tests mock api.github.com. Tape and Cards options do not exist in this copy, so the Site Defaults panel has six options (palette, font, texture, surface, gradient, hero grain). `content-loader.js` uses a synchronous XHR in `<head>` on purpose (no flash); do not make it async. A 403 (including rate limits) is shown as "lacks permission". Sign-out discards unsaved drafts.

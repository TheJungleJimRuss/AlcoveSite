## Gotchas
- iOS 26 Safari colours the status-bar and home-indicator areas from the topmost fixed/sticky layer at each screen edge, and only if its background colour is opaque: keep phone header/tab bar solid and keep full-screen fixed overlays below them.
- Flip sheet: `ONLY=flip` render_layers.py (opt-in) then `SHEET=flip node scripts/make-door-sheet.mjs`. Shell-only strip (15 frames); `.cd-under` (packs+reels) and `.cd-label` get the same per-frame `translateX/scale` as the strip (`xf` in `ab-compare.js`). The 2x sheet is about 29 MB decoded. The cassette stays behind the door (no z-index lift). Strip and resting shell are separate renders, so the turn start and end crossfade 140 ms (WAAPI opacity on `.cd-flip`) to hide edge differences; B->A plays the strip backwards.
- Cassette debug hook: `window.__abDeck` (flip/play/pause/stop/seek/state). Headless/hidden tabs throttle `requestAnimationFrame` and WAAPI: pause the door animation and set `currentTime` by hand to inspect a frame.
- Local preview (python http.server) can serve a stale `wireframe.css`; cache-bust the stylesheet link before judging a screenshot.
- Fader is hidden (`is-away`, no pointer events) while the Home hero fills the view (deliberate). Fader tests must scroll past the hero before dragging. On phones it fades after 1.5s idle (`is-idle`).
- Navbar hover layout shift: pre-allocate transparent borders and keep constant `font-weight: 600` across default/hover/active.
- Never use `mask-composite` or multi-layer masks (headless Chromium 131 ignored the union and knocked out the hero wordmark). Texture tiles are alpha-only and tinted by palette tokens; no blend modes.
- Demo picker on Android: `booking-form.js` sets `accept` to `application/octet-stream` so Chrome shows Files only (any audio/video type in `accept` adds Camera/Camcorder/Recorder, and on-the-spot recordings failed to upload).

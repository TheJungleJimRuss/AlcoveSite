# Cassette player assets

All geometry and textures are original and generated by `build_player.py` (procedural, numpy noise written to `tex/*.png`, used by the Blender file). No third-party scans, HDRIs or models are used, so there is no external licence to record.
Design reference (not copied): top-loading portable cassette recorders in the style of the Sony TC-D5M and Panasonic RQ series.
Since 2026-11-18 the Work page shows top-down renders of this model (`render_layers.py` -> `images/cassette/`); the label text is HTML/CSS. The three.js runtime and the GLB export were removed.

- pav_studio_03_2k.hdr (Poly Haven, CC0): studio lighting for the cassette renders; see assets-src/record-player/LICENSES.md.

# Cassette player assets

All geometry and textures are original and generated by `build_player.py` (procedural, numpy noise written to `tex/*.png`, embedded in
`models/cassette-player.glb` as JPEG). No third-party scans, HDRIs or models are used, so there is no external licence to record.
Design reference (not copied): top-loading portable cassette recorders in the style of the Sony TC-D5M and Panasonic RQ series.
Silkscreen text, glass scratches, label paper grain and the soft shadow are drawn at runtime in `cassette-3d.js`.
